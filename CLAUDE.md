# Instruções do projeto

Leia e siga [AGENTS.md](AGENTS.md), incluindo os requisitos e as regras para testes de fluxo. Para alterações que exijam validação, consulte `.agents/skills/cohida-validacao/SKILL.md`.

Não leia, imprima ou transmita o `.env` da raiz, inclusive por comandos de shell ou ferramentas MCP. Use `.env.example` e dados de teste. Não contorne essa proteção ao executar comandos fora da sandbox.
